TV Station Tycoon v2.3.2 PWA

Changes from v2.3.1:
- Ratings history now stores the exact weekly schedule when a week is completed.
- Tap/click any newly completed week in Ratings to view its historical schedule.
- Historical schedules can be compared with the current schedule.
- Added variable-duration scheduling for 2-hour and 3-hour movies and sports events.
- Long-form programs automatically reserve the following hourly schedule blocks and cannot be placed if they run past sign-off.
- Local program creation now supports 2-hour and 3-hour formats.
- Existing v2.3.1 saves migrate in place. Weeks completed before v2.3.2 do not have retroactive schedule snapshots.

Install/run the same way as v2.3.1. If installed as a PWA, refresh/reopen after deploying so the v2.3.2 service-worker cache replaces v2.3.1.
